# Amyr Klink — Three Solo Voyages

An interactive, educational atlas of three landmark solo voyages, with route animations, stories, and boat illustrations.

**Website:** https://aperico.github.io/amyrklink/

Fully self-contained `index.html`: no external map tiles, API keys, fonts, scripts, or internet requests. Historical routes are schematic reconstructions and not GPS tracks. External interview and photo links are opened only when clicked.

## Publish

In repository **Settings → Pages**, select **Deploy from a branch → main → /(root)** and save.
